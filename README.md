# ArcGIS JavaScript Maps

Interactive map demos built with the [ArcGIS Maps SDK for JavaScript](https://developers.arcgis.com/javascript/latest/) and [Calcite Design System](https://developers.arcgis.com/calcite-design-system/).

**[View the live demos →](https://kdmonroe.github.io/arcgis-js-maps/)**

## Demos

| Demo | Description |
| --- | --- |
| [Point, Line, and Polygon Map](https://kdmonroe.github.io/arcgis-js-maps/demos/point_line_polygon_map.html) | Basic geometry types with custom styling and popups |
| [Maryland Traffic Cameras](https://kdmonroe.github.io/arcgis-js-maps/demos/maryland_traffic_cameras.html) | 3D map of traffic cameras with live feeds |
| [Toronto Roads](https://kdmonroe.github.io/arcgis-js-maps/demos/toronto_roads.html) | Toronto's road network by classification |
| [Buildings Scene](https://kdmonroe.github.io/arcgis-js-maps/demos/buildings_scene.html) | 3D buildings with height-based rendering |
| [Wildfires Map](https://kdmonroe.github.io/arcgis-js-maps/demos/wildfires/index.html) | Active and historic US wildfires with a time slider |
| [Philadelphia County Boundaries](https://kdmonroe.github.io/arcgis-js-maps/demos/philadelphia_map.html) | County outline unioned from neighborhood GeoJSON |
| [Two-State Solution Map](https://kdmonroe.github.io/arcgis-js-maps/demos/two_state_solution_map.html) | Boundaries of Israel, the West Bank, and Gaza |
| [US Power Plants Clustering](https://kdmonroe.github.io/arcgis-js-maps/demos/power_plants_app/index.html) | Power plants clustered and colored by fuel type |
| [OSM Real-Time Amenities Explorer](https://kdmonroe.github.io/arcgis-js-maps/demos/osm_realtime_amenities.html) | Live OpenStreetMap amenity queries via the Overpass API |
| [Alternative Fuel Sources](https://kdmonroe.github.io/arcgis-js-maps/demos/alternative_fuel_sources.html) | Binned heatmap of US alternative fuel stations |
| [LGBTQ Rights Timeline](https://kdmonroe.github.io/arcgis-js-maps/demos/lgbtq_rights_timeline.html) | State LGBTQ protections, 1970–2024 |
| [Assault Weapons Ban Timeline](https://kdmonroe.github.io/arcgis-js-maps/demos/assault_weapons_timeline.html) | State and federal assault weapons laws, 1989–2024 |
| [NASA PACE Earth Observation](https://kdmonroe.github.io/arcgis-js-maps/demos/nasa_pace_viewer.html) | NASA PACE ocean, land, and atmosphere imagery |
| [3D LiDAR Point Cloud Explorer](https://kdmonroe.github.io/arcgis-js-maps/demos/lidar_point_cloud.html) | Classified LiDAR over Barnegat Bay, NJ (SDK 5.0) |
| [Utopia: Fair Representation Act](https://kdmonroe.github.io/arcgis-js-maps/demos/fair_representation_act_utopia.html) | Swipe today's House districts against FairVote's FRA plan |
